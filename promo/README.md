# Промо-ролик Waka

Вертикальный (1080×1920) промо-ролик игры **Waka** длительностью 30 секунд.
Кадры не «нарисованы от руки»: они собираются из **настоящих ассетов игры** —
спрайтов героя по стадиям возраста, котов, редких котов, карты уровня, UI и OST
из `music/`. Спрайтовые анимации разобраны напрямую из Godot-ресурсов
(`scenes/player.tscn`, `assets/enemies/*.tres`), цифры в титрах — из
`data/stages/*.tres` и `scripts/age_manager.gd`, поэтому ролик не расходится с
балансом игры.

## Как это сделано

```
Godot-ресурсы игры ──tools/extract_assets.py──▶ public/assets + src/generated/*.json
                                                        │
                                        src/scenes/*.mjs (Skia/canvas: графика, титры, эффекты)
                                                        │
                                        src/render.mjs ─┤─▶ RGB-кадры ─▶ ffmpeg ─▶ out/*.mp4
                                        src/audio.mjs ──┘              (H.264 + AAC)
```

* Рисование — [`@napi-rs/canvas`](https://www.npmjs.com/package/@napi-rs/canvas) (Skia), шрифт Montserrat с кириллицей.
* Геймплей во 2-й сцене — честная симуляция: герой догоняет ближайшего кота,
  коты бегают кто куда; из этого же прогона берутся звуки поедания, так что
  «чавк» совпадает с кадром.
* Саундтрек — реальный OST игры, сведённый ffmpeg: музыка по сценам, колокольчик
  на редких котах и таблетке, низкие «переходы» на склейках.

## Запуск

```bash
npm install                      # зависимости рендера
python3 -m venv ~/.cache/venv && ~/.cache/venv/bin/pip install imageio-ffmpeg   # ffmpeg, если его нет в системе
                                 # (либо укажите свой: export FFMPEG=/path/to/ffmpeg)

npm run assets                   # вытащить спрайты/музыку из игры + посчитать правила
npm run audio                    # собрать саундтрек
npm run render                   # рендер out/waka-promo-vertical.mp4
```

Полезные режимы:

| Команда | Что делает |
| --- | --- |
| `npm run stats` | прогон по кадрам с яркостью/движением — ловит пустые и застывшие сцены |
| `npm run stills` | отдельные кадры в `out/stills/` для быстрой проверки вёрстки |

Параметры ролика (размер, fps, длительность, раскадровка сцен, музыка) лежат в
`src/config.mjs`; текст титров — там же в `COPY`.

## Раскадровка

| Сцена | Секунды | О чём |
| --- | --- | --- |
| intro | 0.0–3.0 | Логотип WAKA, слоган «Ешь · Взрослей · Выживай», появление котёнка |
| play | 3.0–10.0 | Реальный геймплей на карте игры: погоня за котами, счётчик растёт |
| ageing | 10.0–15.5 | 5 стадий жизни: Младенец → Ребёнок → Подросток → Юноша → Взрослый, скорость падает |
| rare | 15.5–20.5 | 7 редких котов, слоты коллекции заполняются |
| oldage | 20.5–25.5 | 60 секунд до смерти от старости → таблетка молодости → снова младенец |
| victory | 25.5–28.0 | 300 котов, ПОБЕДА |
| outro | 28.0–30.0 | Логотип и слоган |

## Замечание по окружению

В этой песочнице недоступен CDN с Chrome Headless Shell, поэтому вместо
React/Remotion использован рендер «canvas → ffmpeg»: тот же результат, но без
зависимости от браузера. Схема осталась компонентной — одна сцена = один модуль
в `src/scenes/`.

`public/assets/` — копии ассетов игры (создаются `npm run assets`), в git не
хранятся, равно как и `out/` с готовым роликом.
